# PR Measurement Landing Page

Signal AI's PR Measurement product landing page. Showcases how organizations can track, analyze, and report on PR impact with credible, executive-ready intelligence.

## Project Structure

```
├── index.html                 # Main landing page
├── assets/
│   ├── colors_and_type.css   # Design system styles
│   ├── landing.css            # Page-specific styles
│   └── logo/                  # Logo and brand assets
├── README.md
└── .gitignore
```

## Getting Started

### Requirements
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No build step or dependencies required

### Local Development

1. Clone the repository
2. Open `index.html` in your browser

Or use a local server:
```bash
python3 -m http.server 8000
# Visit http://localhost:8000
```

## Assets

The page references external assets:
- `assets/colors_and_type.css` — Brand color palette and typography
- `assets/landing.css` — Layout and component styles  
- `assets/logo/pyramid-red.svg` — Signal AI logo
- Lucide icons (loaded from CDN)
